# Site de Oceanografia

Esse projeto é uma página sobre Oceanografia, desenvolvida como parte do Trabalho Avaliativo  da disciplina de Desenvolvimento Web 

## Sobre o projeto

O site tem informações básicas  sobre a Oceanografia e sua relação com os oceanos, ambientes marinhos e áreas de estudo.

## Tecnologias utilizadas

* HTML
* CSS

## Objetivo

O objetivo do projeto é colocar em prática os conhecimentos de HTML e CSS e aprender a publicar uma página web estática utilizando o GitHub Pages.

## Publicação

O site será publicado utilizando o GitHub Pages.
